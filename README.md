# Sanjeevani Group website

This is a website-only Next.js project. It does not require or start a CMS, API server, or database. The public business directory, search, and category filters run directly in the frontend.

## Run locally

1. Install Node.js 20.9 or newer.
2. Open a terminal in `frontend`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

Update the business directory in `frontend/src/data/businesses.ts`.

The supplied business list contains 18 names, although the brief mentions 17; all 18 supplied names are included.
